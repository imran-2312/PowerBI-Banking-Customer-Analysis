# Power BI Banking Customer Analysis

## 📌 Project Overview

This project is an interactive Power BI banking analysis dashboard designed to transform banking customer data into meaningful business insights.

The project focuses on analyzing customer information, banking behavior, customer demographics, and key performance indicators through data cleaning, DAX calculations, data modeling, and interactive visualizations.

## 🛠️ Tools & Technologies

- Power BI
- DAX
- Microsoft Excel
- CSV Dataset
- Data Visualization
- Data Cleaning
- Data Analysis

## 🎯 Project Objectives

- Analyze banking customer data
- Understand customer demographics and behavior
- Create meaningful KPIs
- Perform data cleaning and transformation
- Build interactive Power BI dashboards
- Use DAX calculations for analysis
- Identify useful business insights from the data

## 📊 Dashboard Features

- Interactive KPI cards
- Customer analysis
- Demographic analysis
- Banking-related insights
- Interactive charts and visualizations
- Filters and slicers
- DAX-based calculations

## 📂 Project Files

- `banking project.pbix` – Power BI dashboard file
- `Banking.csv` – Dataset used for the analysis
- `Banking Data.docx` – Project documentation

## 🔍 Key Skills Demonstrated

- Data Visualization

## 🚀 How to Use

1. Download the `banking project.pbix` file.
2. Open the file using Microsoft Power BI Desktop.
3. If required, update the dataset connection.
4. Explore the dashboard using the available filters, slicers, and visualizations.

The dashboard provides an interactive way to explore banking customer data and helps convert raw data into clear and understandable business insights.
